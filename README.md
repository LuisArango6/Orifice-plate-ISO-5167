# Orifice-plate-ISO-5167
CFD validation of an orifice plate discharge coefficient (Cd) against ISO 5167-2 (Reader-Harris/Gallagher) for an oil &amp; gas water-injection metering case. 2D axisymmetric RANS in ANSYS Fluent, mesh independence study with GCI, 4" line, β = 0.6, flange taps, Re 5×10⁴–5×10⁵.
